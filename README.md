# Blue Lock Builders

Mission
A platform to help developers discover their signature skills ("weapon") through short, focused build challenges and a community that rewards building and growth.

What this repo will build (MVP-1)
Skill Discovery Engine — a lightweight system to deliver mini build challenges, collect solutions, and compute a basic skill profile for each user.

Who this is for
Builders and learners who want to discover and sharpen their core strengths through doing, reviewing, and iterating.
